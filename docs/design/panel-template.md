# パネルの共通雛形（v1.10.5 で実装済み。v2 の P5 で面を「付箋」に改訂）

対象: `Ctrl+L`（質問）、`Ctrl+K`（書き換え）、`Ctrl+E`（コマンドバー）、`Ctrl+J`（提案）、`Ctrl+Shift+F`（ノート検索）、コマンドパレット（`Ctrl+Shift+P`）。同じ面を使うもの: タグを付ける・外すピッカー、教訓のカード、すべてのタブの一覧、ステータスバーの AI のポップオーバー、スニペットの選択。

v1.10.5 より前は6つのオーバーレイが別々の寸法・位置・作りで、同じ操作（入力して選んで実行、Esc で閉じる）なのに見た目が揃っていなかった。ux-review-2026-09.md の C1（位置と寸法）、C2（バッジの「K」）、C3（コマンドバーの「CLI」）に対応して揃えた。**v2（P5）では位置・幅・動き・入力欄の規則はそのままに、面だけを付箋にした**（下の「付箋の面」）。ダイアログ（設定、About など）は付箋ではなく素の「紙」（「ダイアログは紙」）。

## 骨格（上から4段。要らない段は出さない）

| 段 | 高さ | 中身 | 出す条件 |
|---|---|---|---|
| 1. ヘッダー | 44px | 種類のバッジ（言葉）/ 入力欄 / 主ボタン / 閉じる | 常に |
| 2. 文脈 | 28px | 対象のチップ（「選択範囲 · 213文字」「日付ノート · 3ファイル」）、状態の一文 | 対象や状態があるとき |
| 3. 本文 | 行 36px | 結果・候補の行、バナー（未設定・エラー） | 行やバナーがあるとき |
| 4. ヒント | 28px | キーの案内（`Enter` 実行 · `Esc` 閉じる） | 常に |

## 共通の寸法とトークン

- 幅 560px（狭いウィンドウでは左右に 16px の余白）。**全パネルで同じ**で、状態（コマンドの生成中、長いコマンド、結果の有無）で幅を変えない。変わるのは高さだけ。位置は、ヘッダーの下 16px・水平中央。例外は1つ: 対象の文章がノートの上端近くにあって、パネルの下に隠れてしまうときだけ、下端（下から 16px）に出す。**v2 では、ヘッダーとステータスバーは本文の上に浮かぶバー（それぞれ 38px / 24px、`--ov-top` / `--ov-bottom`）なので、この 16px は「バーの下」「バーの上」から数える**（`top: calc(var(--ov-top) + var(--panel-top))`、下端は `bottom: calc(var(--ov-bottom) + var(--panel-top))`。`css/chrome.css`）。バーが入力中に隠れていても（`body.chrome-faded`）、Zen モードでも、パネルの位置は変わらない（位置を動かすとレイアウトが動くため）。パネルを開いている間はフォーカスがパネルにあるので、バーは本文の入力で隠れない。
- 面は**付箋**（下の「付箋の面」。v1.10.5 の背景 `--bg-modal`・枠 1px・角丸 8px・影 `--panel-shadow` は P5 で置き換えた）。フォーカスがパネルの中にあるあいだは、**上端の粘着帯がアクセント色の塗りになる**（v1.10.5 の「枠だけがアクセント色になる」の置き換え。枠は無い）。**入力欄には自分の枠も背景も付けない**（パネル全体が箱）。`Ctrl+K`（書き換え）も同じ見た目で、アンバーの枠は使わない。違いはラベル（Rewrite）とヒント（Enter で置き換え）で示す。
- 余白は 4px の倍数: 内側 12px、要素の間 8px。文字は 13px（入力は 14px、補助・ヒントは 12px / 11px）。太さは 400 と 600 だけ。
- バッジ（ラベル）: 塗りなし・枠なし。明るいアクセント色（#a6c26a）の文字 12px/600 と、右に 1px の区切り線。中身は言葉にする（Ask / Rewrite / Command / Suggest / Search / Commands）。「K」「CLI」「AI」は使わない。塗りつぶしはボタンだけに使うので、バッジをボタンと見間違えない（いまの実装は緑の塗りで、実行ボタンと同じ見た目）。
- 主ボタン: アクセント色の地に白文字、高さ 28px。1つのパネルに1つだけ。副は枠線、三次は薄いグレーの塗り（文字だけにするとボタンに見えない）。
- 3つの部品の見分け: ラベル（バッジ）は文字だけ、ボタンは塗りか枠線、チップ（「選択範囲 · 213文字」）は薄い灰色の丸い地。
- キー表示 `kbd`: 1px の枠、角丸 4px、等幅 11px。
- 選択行: アクセント色 20% の地と、左端 2px のアクセント線。フォーカスの輪郭は全体共通（`:focus-visible`）。付箋の紙の色は薄いアクセントの重ねなので、行の区切りやチップ（薄い膜）はその上でそのまま読める（5 つのアクセントと自分で指定した色で、文字の 4.5:1 を `tests/look_contrast_test.mjs` が確かめる）。

## 付箋の面（v2 P5）

面だけを変えた。位置・幅 560px・フェード・入力欄の規則・マークアップ・id・クラス・`panel_fade.js` は v1.10.5 のまま。対象の根は 6 つのセレクタ（`.inline-prompt-bar`〔質問・書き換え・コマンドバー〕、`.quick-pick-modal`〔パレット・検索・タグ・教訓〕、`.jev-action-panel`、`.tab-list-panel`、`.status-ai-pop`、`#slot-quick-selector`）で、**面の規則は `style.css` の末尾の 1 か所**（「The sticky note」）に書く。パネルごとの規則は面（背景・枠・角丸・影）について何も言わない。

- **根**: `background: transparent`、`border: 0`、`border-radius: 0`（角は直角。回転もしない: 文字の鮮明さのため）、`box-shadow: var(--note-shadow)`（長方形の静的な影）、`padding-bottom: var(--note-fold)`（14px。折り目の帯。どの子もここには描かれない）。
- **紙**は根の `::before`（`inset: 0`、`z-index: -1`、`pointer-events: none`）。背景を 3 枚重ねる: 粘着帯（上端の全幅 6px、`--note-strip`）、薄いアクセント（`--note-tint` = `rgb(var(--accent-rgb) / var(--note-tint-a))`）、下地の `--sheet`。`color-mix()` は使わない（macOS 10.15 = Safari 15.6 に無い）ので、色は計算ではなく背景の重ねで作る。したがって**自分で指定したアクセントも `--accent-rgb` だけで付箋の色になる**。墨の地では暗い紙（`--sheet` はページより明るい。明るい紙にはしない）。右下の折り目は、紙の層だけに `clip-path: polygon(...)`（`--note-fold` の三角を切り取る）。
- **折り返し**は根の `::after`（右下の `--note-fold` の正方形、左上半分が `--note-flap` の三角）。切り欠きとちょうど鏡像になる。
- **粘着帯とフォーカス**: 帯は `--note-strip` の色で描く。普段は `--note-tape`（アクセント 35%）、**フォーカスがパネルの中にあるあいだ**（`:focus-within`）は `--note-tape-focus`（墨は `--accent-label`、紙は `--accent-color`）の塗り。帯は紙・ページとの 3:1（WCAG 1.4.11）を全アクセントで `tests/look_contrast_test.mjs` が確かめる。Ctrl+J のパネルは入力がエディタにあるので、帯は普段のままの薄い色。
- **根には `clip-path`・`filter`・`backdrop-filter`・`will-change`・`opacity` を書かない**。`clip-path` は影まで切る。`filter: drop-shadow` は文字をグレースケールのアンチエイリアスにし、再ラスタライズの費用もある。`opacity` は閉じるフェード（`.panel-fading`）の持ち物。影は静的な `box-shadow` だけなので、8 万行のノートをスクロールしている間にパネルを開いていても、スクロールで再描画されない。
- **折り目の帯**（`padding-bottom`）で、どのパネルも高さが 14px 増える。選択行の塗りや右端のヒントが切り欠きに描かれることは無い。
- **強制色**（Windows のハイコントラスト）: 影と色は描かれないので、根は `Canvas` の背景に 1px の `CanvasText` の枠、紙と折り返しは非表示、折り目の帯は 0、フォーカスは 2px の `Highlight` の輪郭。
- **暗幕**: パレット・検索・タグ・教訓（モーダルな付箋）は `--bg-scrim-note`（墨 0.32、紙 0.14）。ダイアログの `--bg-scrim`（墨 0.6、紙 0.26）より薄い。付箋は軽い呼び出しで、画面ではないため。ぼかしは掛けない（全画面の `backdrop-filter` は描画が重い）。
- **位置の定数**はヘッダー・ステータスバーのオーバーレイに合わせてある（`css/chrome.css`: `--ov-top` / `--ov-bottom`）。`dockPanelBar` の「下に避ける」判定の上端は、バー自身の計算済みの `top` を読む（定数 16 は、スタイルを持たないページのときの代わり）。**Ctrl+J のパネルは `#workspace` の子**（質問・コマンドバーと同じ）で、分割していても窓の水平中央に出る。エディタの箱の中には置かない（影が切れる）。

試験: `tests/panel_template_test.mjs`（面の規則 5〜8 章と、その規則を壊した写しが落ちること）、`tests/look_contrast_test.mjs`（紙の上の文字、粘着帯）、スモーク 118（位置）と 119（面の実測値、強制色、動きを減らす設定）。

## ダイアログは紙（v2 P5）

設定・About・設定パッケージ・確認など `.modal-card` のダイアログは付箋にしない。付箋は一時的な呼び出し（入力して選んで実行して、フォーカスが外れたら消える）で、ダイアログは文書のように読んで直す画面なので、粘着帯と折り目はヘッダーとフッターに触れてしまう。**素の「紙」**にする: `--sheet`、枠なし、角は直角、`--shadow-modal` の影で浮かせる。粘着帯・折り目・疑似要素は付けない。強制色では 1px の `CanvasText` の枠。寸法（560px、48 / 40 / 36 / 28）・スイッチ・ボタンの 3 段階は上のまま。付箋は軽い呼び出し、紙は本格的な画面、という階層を保つ。

## 動き

- 開く: 120ms のフェード + 4px 上から。閉じる: 200ms のフェード。
- フォーカスがパネルの外へ出たら、猶予 0.4秒のあとにフェードして閉じる。入力が残っているときは閉じない。ウィンドウ全体が非アクティブになっただけでは閉じない。
- OS の「アニメーションを減らす」が有効なら、フェードは無し。

## 6つのパネルへの当てはめ

| パネル | バッジ | 入力欄 | 文脈 | 本文 | ヒント |
|---|---|---|---|---|---|
| `Ctrl+L` | Ask | 指示 | 対象のチップ | （バナー） | Enter 実行 · Esc 閉じる |
| `Ctrl+K` | Rewrite | 書き換えの指示 | 対象のチップ | （バナー） | 同上 |
| `Ctrl+E` | Command / AI command | コマンド / 説明文 | 対象 | 生成したコマンドの確認 | Tab モード切替 · Enter 実行 |
| `Ctrl+J` | Suggest | （なし。自動提案） | 対象 | 候補3行（動詞タグ Write / Delegate / Run） | Tab 移動 · Enter 決定 · `Ctrl+1〜3` |
| `Ctrl+Shift+F` | Search | 検索語 | 「日付ノート · Nファイル」 | 該当行（ファイル・行番号を右に） | Enter 開く · Tab 引用 |
| `Ctrl+Shift+P` | Commands | コマンド名 | — | コマンド行（アイコン・名前・ショートカット） | ↑↓ 移動 · Enter 実行 |

## 実装の進め方（見た目を大きく変えないために）

1. 共通の CSS クラス（`.panel`、`.panel-head`、`.panel-context`、`.panel-body`、`.panel-row`、`.panel-hints`）とトークンを1か所に定義する。
2. 6つのパネルを、1つずつ新しいクラスへ載せ替える。載せ替えのたびに docshots で撮り直し、変更前後の画素差を確認する。
3. 位置決めは1つの関数にまとめる（上部中央）。`Ctrl+K` が選択行を隠す問題も、ここで解消する。
4. 閉じる動き（フォーカスアウトでフェード）は、共通の `closePanel()` に入れる。
5. `role=dialog`、`aria-modal`、フォーカストラップは、前回入れた `a11y.js` をそのまま使う。
