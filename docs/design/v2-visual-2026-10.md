# v2: syki::sok の見た目の刷新（草案 2026-10-04）

状態: **草案。2026-10-04 に実装の開始を了承（ブランチ `v2`、worktree は `../md-memo-v2`）。** ユーザーの草案（スケッチ 3 枚と文章）と、画面案（アーティファクト `claude.ai/artifact/AGQjg4MqrN9KmMeTk5piov`、非公開。ソースは作業用の `syki-sok-v2.html`）への返答 4 回を、ここに合意事項として書き起こす。色・寸法の数字は画面案のもので、**実アプリで見て決め直す前提**（特にタブの幅）。

## 1. 目的と範囲

- 目的: アプリの見た目を「紙」「本」「付箋」の世界観に統一する。**主に見た目の変更**で、機能は減らさない。
- 範囲: 窓の面（紙と墨の 2 つの地、アクセント）、タブ、ヘッダー、フッター、行番号、1 ページ・左右ページ・見開きプレビュー・プレビューのみの 4 つの表示、付箋のパネル。
- 範囲外: **改名**（将来行うときは**別リポジトリの新しいアプリ**とする。このリポジトリの md-memo は改名しない）、`ku::sok`（録音デバイス）との連携（**今は考えない**）、機能の追加。
- 範囲に入れるもの（ユーザーの希望）: 見た目を**個人が少し変えられる**設定（§4.7）。

## 2. 名前と世界観

- アプリ名は **`syki::sok`**（コンセプト画像では `Syki::sok`）。由来は色即是空・空即是色で、syki = 色、ku = 空。
- **`ku::sok` は、syki::sok 専用のライフログとして音声を録音する「デバイス」**（開発中）。アプリのモードではない。コンセプト画像は、左が `ku::sok [VOICE HARMONIC]`（青みの墨色の紙に同心円の波紋）、右が `Syki::sok [RATIO: 1 · 1/2 · φ/2 · 1/√2]`（白い紙に角丸の太い横棒 4 本。棒の長さがその比）。
- 世界観: モノトーン、アクセントは 1 色、枠線ではなく色の差と影で段差を作る。ライトは紙っぽく、ダークは青みのある墨色。

## 3. 合意した事項（画面案への返答の要約）

1. イメージは合っている。
2. タブ: **行間 0、角はすべて直角**、幅は**実アプリで見て決める**（当面は画面案の 6px）、展開すると 200px で名前が読める。
3. タブの出し方（モード別）: **1 ページと見開きプレビューは左だけ、左右ページは左右、プレビューのみはなし**。位置の選択（左・右・上）は画面案から外した。
4. **行番号は必要**（左の余白に薄く）。
5. タイトルは**ファイル名のみ**（「01 / syki::sok」は出さない）。
6. アクセントは**現行の 4 テーマと同じ**（Dark Olive が既定、Classic Blue、Forest Teal、Charcoal Monochrome）に、**朱を 1 つ追加**。
7. 角丸は少し小さく（本 11px）。**上の角丸はなし**（OS のタイトルバーが上に付くため）、**下だけ**丸い。窓の周りの余白（クリアランス）はなし。
8. フッターの凹みは弱く、**影は上と左だけ**。
9. プレビューは、紙が**上下いっぱい**に広がり、**ヘッダーとフッターも出す**（紙・机の余白・編集ページのそれぞれの色に合わせた帯）。
10. **既存の機能は v2 でも残す**（カーソルオーラ、ゴースト、検索バー、結果ブロックの帯など。画面案には出さない）。
11. **Zen モード**（`Shift+F11`）は、**余白は変えない**（現行どおり本文の左右を少し広げる。「余白を消す」はやめた）。**バーはマウスを動かしても戻らない**（窓の上端・下端に 150ms とどまるか `F6` で戻る）、**通知は見えなくする**（読み上げ用には残す。保存・設定の失敗と録音中だけは例外で、フッターを出す）、タブの帯は隠す。オーバーレイの自動非表示は、Zen でなくても既定で働く（入力・スクロールで消え、マウスを動かすと戻る）。
12. **起動の速さと 8 万行のノートの動きを最優先**で測る。見た目の個人設定は、無料（未使用なら何も作らない、設定の値は CSS 変数 1 つで済む）である範囲で入れる。

## 4. 仕様

### 4.1 面と色

2 つの地を持つ。トークンは画面案の `.desk` を台帳にする。

| トークン | 紙（ライト） | 墨（ダーク） | 用途 |
| --- | --- | --- | --- |
| `--wall` | `#e6e6e1` | `#06070a` | 机。プレビューの余白、タブの下地 |
| `--page` | `#fbfbf9` | `#0e0f17` | 編集ページ |
| `--sheet` | `#ffffff` | `#181a26` | プレビューの紙、付箋の下地 |
| `--ink` / `--ink-2` | `#16171b` / `#6a6b73` | `#dcdde3` / `#8b8d99` | 本文 / 補助の文字 |
| `--hair` | 文字色 9% | 文字色 7% | 薄い罫線（ヘッダーとフッターの境だけ） |
| `--shade` | 20,22,30 の 10% | 黒の 50% | 影 |

- アクセントは各テーマの `accent-color` / `accent-hover` / `accent-label` を、紙では `accent-color`、墨では `accent-hover`（文字は `accent-label`）に当てる。朱（案）は `#b8472c` / `#cf5c3c` / `#f1977c`。
- **現行は暗い配色だけ**（`light-theme` が無い）。紙（ライト）は v2 で**新しく作る**。紙と墨の両方でコントラストを確かめる（§6）。
- 角丸: 窓の下の角と本の下の角 11px、チップ 8px、ボタン 9px、付箋とタブは角丸なし／直角。上の角は丸めない。

### 4.2 4 つの表示

| 表示 | 構成 | タブ |
| --- | --- | --- |
| 1 ページ | 編集ページ 1 つ | 左のみ |
| 左右ページ | 編集ページ 2 つ。中央にノド（影とドット） | 左右 |
| 見開きプレビュー | 左が編集、右がプレビュー（机の色の地に紙が浮く） | 左のみ |
| プレビューのみ | プレビューが窓いっぱい（中央寄せ。幅は 800px まで） | なし |

- ノド: 線を引かず、中央に横方向の影と、両側へ薄れるドットの帯を置く。
- プレビューの紙: 枠線なし。左右に机の余白（34px。プレビューのみは中央 800px）、上下は窓いっぱい。本文と同じように、ヘッダーとフッターの下をくぐってスクロールする。
- 現行の構造との対応: `#editor-pane`（+ `#line-numbers`）、`#pane-resizer`、`#secondary-pane`（`#secondary-pane-header` を含む）、`#preview-pane`、`#preview-badge`。**仕切りはドラッグできる現行の `#pane-resizer` を残し、見た目だけをノドにする**。
- 仕切りのキーボード操作（草案は「キーボードでも操作できる現行の挙動を落とさない」と書いたが、**事実と違った**）: 現行（v1.14.0）の `#pane-resizer` は素の `div` で、あるのはドラッグ（15%〜85%）とダブルクリック（50:50）だけで、**キーボード操作は無かった**。落とすものは無く、**P4a が新設した**: `role="separator"`・`tabindex="0"`・`aria-valuenow`、`F6` の巡回の停止点（本文 → ヘッダー → 左のタブの帯 → 右のタブの帯 → 仕切り → フッター。エディタは `Tab` をインデントに使うので、`Tab` では届かない）、`←` `→`（2 ポイント、`Shift` で 10）、`Home` `End`（15% / 85%）、`Enter`（半分ずつ）、`Esc`（本文に戻る）。左のページはノドの幅を引いた残りの割合で決めるので、半分ずつのとき 2 つのページはノドの幅によらず同じ幅になる。幅は保存しない（現行と同じ）。仕切りの見た目の設定 `appearance.splitBoundary`（`dots` = ノド・既定 / `shade` = 影だけ / `line` = 細い線。計画書の初版は既定を `gutter` と書いたが、値の名前は `dots`）は P4b。

### 4.3 タブ（索引）

- 細い帯として窓の端に並ぶ。幅 6px（実アプリで決め直す）。重ねる（ホバー、フォーカス）と 200px に広がり、ファイル名が読める。
- 色: 選択中がアクセント 100%、離れるほど薄く（`max(20%, 68% − 12% × 距離)`）。間隔 0、1px の仕切り、**角は直角**。
- 未保存の印（点）、ドラッグでの並べ替え（濃淡が動く）、クリックで切り替え、キーボード（フォーカスで広がる）。
- 画面案では未実装で、**実装で決める**もの: 20 個を超えたときの高さ（詰める／スクロール。現行の `tab_overflow.js` の考え方を引く）、6px の当たり判定（見えない当たり判定を広げる。右端はスクロールバーと競合するので、画面案では 9px 空けた）、全タブ一覧（現行の `btn-all-tabs`）の行き先、タブを上に出す設定（草案にあったが、画面案では外した）。

### 4.4 ヘッダー

- タイトルバー相当の固定の帯はなし。窓の上端に**オーバーレイ**として、左にファイル名のみ（本文の左端にそろえる）、右にアイコン列（現行の `#header-actions` を引き継ぐ）。薄い罫線で本文との境を表す。
- 本文はヘッダーの下をくぐってスクロールする。背景は半透明（すりガラスは設定。§6）。
- 入力中とスクロール中はフェードアウトし、**マウスを動かすと戻る**。キーボードでも出せる（フォーカスが入れば出る。`:focus-within`）。**日本語入力では `keydown` の `key` が `Process` になるので、`input` と `compositionstart` で検出する**（画面案で見つかった）。
- 現行の **Zen モード**は 2 つある。`body.zen-active`（入力中にバーを薄くする）は、この自動非表示に**吸収されて無くなる**。`body.zen-mode`（`Shift+F11` の永続）は残し、上の 11 のとおり、**バーはマウスで戻らず、通知は見えなくし（失敗と録音中は出す）、余白は変えない**。

### 4.5 フッターと行番号

- フッター: 左に行・列・文字数（現行の `#stat-cursor` ほか）、右に Git・IME・文字コードのチップ。**チップは紙が凹んだ表現で、影は上と左だけ**（強くしない）。ヘッダーと同じオーバーレイで、同じ条件で消える・戻る。
- 行番号: 左の余白に薄く（不透明度 55% 程度。コントラストは §6）。折り返した行は論理行の先頭の行に付ける（現行の `line_gutter.js` の挙動を保つ）。

### 4.6 付箋のパネル

- `Ctrl+K`、`Ctrl+L`、`Ctrl+J`、`Ctrl+E` などのパネルを、付箋のような紙で出す。薄いアクセント色の紙、上に粘着帯、右下の折り目、持ち上がった影。傾けない（文字の鮮明さを優先）。
- 現行は v1.10.5 で 6 種のパネルを幅 560px・上端中央にそろえた（`docs/design/panel-template.md`、`tests/panel_template_test.mjs`、`panel_fade.js`）。**位置・幅・フェード・入力欄の規則は保ち、面の見た目だけを付箋にする**。雛形の文書とテストを同時に改訂する。
- **実装した形（P5）**: 付箋は 6 つのセレクタの根（質問・書き換え・コマンドバー、パレット・検索・タグ・教訓、Quick Actions、すべてのタブ、AI のポップオーバー、スニペットの選択）で、面は `style.css` の 1 か所。紙は `::before` の 3 枚重ね（粘着帯、薄いアクセント、`--sheet`）で、色は `rgb(var(--accent-rgb) / …)` の重ね（`color-mix()` は使わない）。根自身には `clip-path`・`filter` を使わない（影と文字の鮮明さのため）。**墨の地では暗い紙**（`--sheet` はページより明るい）。フォーカスは粘着帯がアクセントの塗りになることで示す（v1.10.5 の「枠がアクセント色になる」の置き換え）。モーダルな付箋の暗幕はダイアログより薄い。**設定画面などのダイアログは付箋ではなく素の「紙」**（`--sheet`・枠なし・影、粘着帯と折り目なし）。Ctrl+J のパネルは `#workspace` の子になった。詳細は `docs/design/panel-template.md` の「付箋の面」「ダイアログは紙」。

### 4.7 個人の見た目の設定（設定画面に「外観」の節）

未設定なら画面案どおり。どれも**値を CSS 変数に流すだけ**で、読み込み時に重い処理をしない。

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| 地 | 墨（ダーク）／紙（ライト） | 墨（これまでの見た目を引き継ぐ） |
| アクセント | 現行 4 テーマ＋朱＋自分で色を指定（`#rrggbb`） | Dark Olive |
| 上下の透過 | 不透明／うすい／すりガラス | P2 の測定で決める（既定は軽いほう） |
| 分割の境界（`appearance.splitBoundary`） | `dots` ノド（影とドット）／`shade` 影だけ／`line` 細い線 | ノド（`dots`。`<body>` に `data-boundary` を付けない状態。`shade` と `line` だけが属性になる） |
| エディタのフォント | 既定／インストール済みのフォント名（入力）。大きさは現行の設定を使う | 既定 |

- 保存先は `config.general` ではなく新しい `appearance`（JS 側。Go は設定を JSON のまま持つ）。設定パッケージの書き出し・読み込み、`config.get` の表示に載るか確認する。
- フォントは**同梱しない**（サイズが増える）。システムのフォントを名前で選ぶ。
- 自分で指定したアクセントは、文字・塗りのコントラスト（§6）を自動で確かめ、足りなければ文字色を白／黒に切り替える。

## 6. 懸念と、決めるための測定

- **すりガラス**（`backdrop-filter`）: 本文のスクロールに重ねると描画の負荷が増えうる。常駐 5〜15MB・起動 15ms 未満という軽さが売りなので、**8 万行のノートをスクロールして、フレーム時間・GPU・メモリを測ってから既定を決める**。重ければ「半透明のグラデーションだけ」を既定にして、すりガラスは設定にする。Mac（WKWebView）は `-webkit-backdrop-filter` で、実機未確認。
- **キーボードとスクリーンリーダー**: ヘッダーとフッターを隠しても、フォーカスで出る・読み上げから外れない。`aria-live` の状態表示は隠さない。
- **強制色（ハイコントラスト）**: 現行にも対応はない（`forced-colors` の記述なし）。枠線をなくす v2 では**枠線へ戻す規則を入れる**。タブの濃淡は強制色では枠で区別する。
- **コントラスト**: 紙の薄いタブ、行番号（不透明度 55%）、アクセント文字を、紙と墨の両方で測る。足りなければ濃さを上げる。
- **動き**: `prefers-reduced-motion` で、フェード、タブの展開、付箋の降りる動きを止める。
- **下の角丸と OS の角丸**: Windows 11 と macOS は窓を OS が丸める。アプリ側の角丸と二重に見えないか、実機で確かめる（Windows 10 は直角）。
- **右端のタブとスクロールバー**、**6px の当たり判定**、**20 個超のタブ**（§4.3）。
- **日英のマニュアルの図 130 枚と GIF 11 本が、すべて撮り直し**になる（`tools/docshots`）。

## 9. 画面案の使い方

画面案は、見た目の合意のための**使い捨て**。実装は現行の `frontend/` に対して行い、画面案のコードは持ち込まない（トークンの値と寸法だけを引き継ぐ）。画面案の「見てほしい点」「未確認」の 2 つの節は、§6 に移した。
