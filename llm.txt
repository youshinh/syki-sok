# syki::sok

> An instant, featherweight Markdown scratchpad with AI right at your cursor.
> Go core + OS native WebView (WebView2 on Windows, WKWebView on macOS). Zero Electron.
> Memory: 5–15 MB idle. Wake time: < 15 ms. Storage: Plain local `.md` files.

---

## 1. System Overview & Philosophy

syki::sok is designed as a zero-resistance buffer for thoughts before opening heavy knowledge bases like Obsidian or Notion.
- **In-Place AI (No Chat Windows)**: AI operates directly on the editor surface. Outputs land directly below the cursor without context loss or window hopping.
- **Parallel Multimodal Ingest**: Stream voice, paste screenshots with OCR, drop files from mobile via QR, or type Markdown simultaneously.
- **Text as Command Line & Agent Dispatch**: Pipe text into shell commands or delegate tasks to autonomous coding agents (Claude Code, Codex, Antigravity).
- **Extreme Efficiency**: 5–15 MB idle memory footprint, summons in under 15 ms with global hotkeys. 100% offline capable.

## 3. Core Functional Details

### 3.1 In-Place AI (`Ctrl+L`)
- Select text (or leave cursor on line) and press `Ctrl+L`.
- Type instruction (e.g., "Translate to English", "Summarize as bullets", "Make concise").
- Output streams directly below selection wrapped in a transient glow. The original text is preserved.

### 3.2 Ghost-Text Inline Prediction (`Tab`)
- Powered by local models (e.g., Ollama with Qwen 2.5 / Gemma 4).
- As you type, upcoming phrasing appears as faint grey text.
- Hit `Tab` to accept immediately, or keep typing to ignore.

### 3.3 Voice & Vision Ingest
- **Voice Rescue (`Ctrl+Shift+R`)**: Real-time microphone audio transcription with automated grammar cleanup. When text is selected, voice acts as a direct editing prompt.
- **Smart Paste (`Ctrl+V`)**: HTML and spreadsheets convert to clean Markdown tables automatically. Image pastes trigger local OCR.
- **Mobile Drop (`Ctrl+Shift+U`)**: Displays a local QR code. Scan with a smartphone camera to transfer photos, voice memos, and notes directly into today's note without installing an app.
- **Hot Folder**: Drop media files into the configured `inbox` directory for automatic background transcription and OCR.

### 3.4 Command Bar & Agent Delegation (`Ctrl+E` / `Ctrl+Enter`)
- **CLI Pipe (`Ctrl+E`)**: Selected lines stream as stdin to any shell command (`jq`, `sort -u`, `prettier --stdin-filepath foo.json`).
- **AI Shell Generator (`Ctrl+E` -> `Tab`)**: Describe what you want in natural language (e.g., "Extract email addresses"); AI generates the verified one-liner with AST safety guardrails.
- **Agent Slots (`{{ @claude ... }}`)**: Pressing `Ctrl+Enter` runs autonomous coding agents in the background. Results append into `<!-- syki:res -->` blocks.
- **Lessons Invariant (`lessons/<agent>.md`)**: If an agent fails, save a lesson rule. Up to 30 verified rules auto-inject into future agent prompts to prevent repeat mistakes.

## 4. Headless Control, CLI & JSON-RPC API

syki::sok can be controlled programmatically from terminal pipelines and external AI agents:

### 4.1 Shell Pipe
```bash
cat build.log | syki "Build Output"    # Streams terminal log directly into active daily note
git status | syki "Git Snapshot"       # Appends with markdown heading
```

### 4.2 CLI (`syki-cli`)
```bash
syki-cli buffer get                    # Read active editor content
echo "- [ ] Task" | syki buffer append # Append text to current buffer
syki-cli agent install-skill           # Install Claude Code / Codex skill definitions
```

### 4.3 JSON-RPC Protocol (Local Port / Socket)
- `buffer.get`: Returns current active document text and cursor position.
- `buffer.append`: Appends text to document with optional heading.
- `buffer.replaceSelection`: Replaces or inserts text at caret.
- `note.search`: Fast indexed search across all scrap files.

## 5. Storage & Configuration

- **Daily Scraps**: Stored as plain `.md` files at `scraps/YYYY-MM-DD.md`.
- **Git Sync**: Automatic background commit & push supported on every edit or timer.
- **Obsidian / Logseq Compatible**: Set storage root directly to your existing Obsidian Vault.
- **Config**: JSON file storing model endpoints (Ollama, OpenAI, Anthropic, Gemini, DeepSeek, LocalAI), shortcuts, and theme colors.
