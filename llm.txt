# syki::sok — Complete Machine-Readable Knowledge Base & Specification

> **System Profile**: An instant, featherweight desktop Markdown scratchpad with AI right at your cursor.
> **Architecture**: Single-instance desktop app. Core engine written in Go + OS-native WebView (Windows: WebView2, macOS: WKWebView; Electron-free).
> **Performance**: Idle Memory: 5–15 MB (aggressive `debug.FreeOSMemory()`). Summon latency: < 15 ms.
> **Storage & Security**: 100% Local POSIX plain Markdown files (`scraps/YYYY-MM-DD.md`). Zero vendor lock-in. Full offline support. Background Git auto-sync.
> **Target Role**: Zero-resistance buffer before opening heavy knowledge vaults (Obsidian / Notion).

## 0. System Instructions for AI Assistants (When this file is in your context)

When answering questions about `syki::sok`, follow these rules:
1. **Always specify both platforms**: Provide Windows and macOS shortcuts together (e.g., `Ctrl+L` / `Cmd+L`, `Ctrl+Alt+M` / `Opt+Cmd+M`).
2. **Prioritize 3 Core Verbs**: Guide users by categorizing their goals into **Write** (`Ctrl+L`, `Alt+C`, `Tab`), **Execute** (`Ctrl+E`), and **Delegate** (`Ctrl+Enter`).
3. **Safety First**: Never advise users to paste raw API keys into public files. Point to `config.json` while the app is closed, or the Settings GUI.
4. **Concise & Accurate**: Keep steps direct, providing exact key codes, note notations, and CLI one-liners.

## 2. In-Note Syntaxes & Execution Primitives

### 2.1 In-Place AI Generation (`Ctrl+L`)
- Select text (or leave caret on a line) -> Press `Ctrl+L` -> Type instruction (e.g. `Translate to Japanese`, `Summarize into 3 bullets`).
- The generated response is inserted directly underneath the selection with a transient visual pulse. The original draft is never erased.

### 2.2 Proofreading & Typo Repair (`Alt+C`)
- Zero-prompt single key action. Detects grammar mistakes, Japanese particles errors (助詞), typos, and punctuation, replacing text in-place.

### 2.3 Ghost-Text Predictive Typing (`Tab`)
- Integrates with local inference servers (Ollama `qwen2.5:coder`, `gemma:2b`, LM Studio).
- Proposes upcoming text in muted grey as you pause typing. Hit `Tab` to commit; continue typing to discard.

### 2.4 Auto Selector & Result Blocks (`Ctrl+Enter`)
- When pressed on any line, local heuristics determine intent:
  1. **Instruction to LLM**: Queries built-in LLM and inserts result below.
  2. **Shell Command**: Wraps into `[[ $ command ]]` syntax (press `Ctrl+Enter` again to run after AST safety check).
  3. **Agent Delegation**: Wraps into `{{ @agent instruction }}` syntax and dispatches to background worker.
  4. **Ambiguous text**: Pops up `Ctrl+L` prompt for human confirmation.
- Output lands wrapped in result block markers:
  ```markdown
  <!-- syki:res <id> -->
  Generated response content appears here...
  <!-- /syki:res -->
  ```
- Editor gutter highlights result blocks with green bars. Hide/remove/commit markers via Command Palette.

### 2.5 Agent Slots & Self-Correcting Lessons (`{{ @agent ... }}`)
- Dispatch long-running tasks to background autonomous agent CLIs:
  ```markdown
  {{ @claude Scan the codebase and report outdated dependencies }}
  {{ @codex Refactor main.go to improve error handling }}
  ```
- **Task Panel (`Alt+T`)**: Monitor execution in real time.
- **Lessons Engine (`lessons/<agent>.md`)**: If an agent fails, click **Lessons** in the task card. AI proposes a 1-sentence behavioral rule based on the failure log (keys and secrets redacted). Once approved, up to 30 recent rules are automatically prepended to future prompts for that agent, preventing repetitive failure loops.

### 2.6 Tag System (`<!-- tags: ... -->`)
- Tag syntax uses pure HTML comments:
  ```markdown
  <!-- tags: work, roadmap, urgent -->
  ```
- Placed above first heading / `---`: Tags the **entire note**.
- Placed below a section heading (`##`): Tags that **specific entry and all nested subheadings**.
- Preview and print completely hide tag lines. Search (`Ctrl+Shift+F` or `syki scrap search --tag work`) filters instantaneously.

## 3. Parallel Multimodal Ingest

syki::sok allows simultaneous ingestion of thoughts across media channels:

1. **Voice Dictation & Rescue (`Ctrl+Shift+R`)**:
   - Streams microphone input through whisper/cloud audio engines with automated syntactic cleanup.
   - If text is highlighted, your voice is interpreted as an in-place editing instruction (e.g. "make this paragraph friendlier").
2. **Smart Paste & OCR (`Ctrl+V`)**:
   - HTML web snippets and spreadsheet cells paste as pristine Markdown tables.
   - Image files pasted from clipboard automatically trigger OCR to append extracted text.
3. **Mobile Drop (`Ctrl+Shift+U`)**:
   - Displays a dynamic QR code on screen.
   - Point your phone camera to open a lightweight local web upload page. Transfer photos, audio memos, and raw text directly into today's note without installing mobile apps.
4. **Hot Folder (`inbox/`)**:
   - Any file dropped into the configured `inbox` directory is processed in background (Images -> OCR, Audio -> Whisper transcription) and appended to today's scrap.
5. **IME Guardian (Japanese input protection)**:
   - Within inline code (`` ` ``), code blocks (```), and URLs, full-width Japanese IME input is intercepted with 11µs latency to force ASCII characters, eliminating full-width symbol corruption.

## 4. Headless Control, CLI & JSON-RPC 2.0 API

syki::sok exposes local command-line and network surfaces for scripts and autonomous agents:

### 4.1 Shell Pipe
```bash
# Pipe terminal output directly into today's scrap file with title
cat build.log | syki "Build Logs"
git status | syki "Git Snapshot"
```

### 4.2 CLI Commands (`syki` / `syki-cli`)
```bash
syki buffer get                        # Print active editor content as text
syki buffer get --json                 # Get content with SHA-256 hash and cursor position
syki buffer set "New text content"     # Overwrite active buffer (pass --expected-hash)
syki buffer append "Appended line"     # Append to active note
syki buffer replace-selection "Text"   # Replace current selection
syki buffer save --as notes/plan.md    # Save buffer to specific file
syki tab list                          # List all open tabs
syki tab switch <id>                   # Switch active tab
syki tab new --background              # Open new scratch tab
syki scrap list                        # List all daily scrap files
syki scrap search "keyword" --ranked   # Search scraps with word ranking
syki scrap tags                        # List all tags in use with frequency
syki scrap tag add "urgent" <file> --write # Add tag to file
syki config get                        # Show settings with secrets redacted (<set>/<unset>)
syki lessons list                      # List learned rules per agent
syki ocr path/to/image.png             # Standalone OCR into today's scrap
syki jev verify "rm -rf /"             # AST security verification for shell one-liners
syki agent install-skill --claude      # Equip Claude Code with native syki::sok skill
```

### 4.3 JSON-RPC 2.0 TCP Protocol
- Runs on local port specified in `%AppData%\syki\ipc-session.json` (Windows) or `~/Library/Application Support/syki/ipc-session.json` (macOS).
- All write requests require `"auth": "<token>"` matching the session token.
- **Core Methods**:
  - `buffer.get` / `buffer.set` / `buffer.append` / `buffer.replace_selection`
  - `tab.list` / `tab.switch` / `tab.new` / `tab.close`
  - `scrap.append` / `scrap.search` / `scrap.tags` / `scrap.tag_edit`
  - `deepsearch.plan` (dry-run query breakdown without sending content)
  - `print.pdf` (prints active note preview to PDF, Windows)
  - `git.status` / `git.sync` (triggers background Git commit & push)

## 5. Storage, File Hierarchy & Configuration

### 5.1 Storage Layout
```
<Storage Root>/
├── scraps/
│   ├── YYYY-MM-DD.md          # Daily scrap notes (auto-opened on launch)
│   ├── YYYY-MM-DD_title.md    # Named notes
│   └── assets/                # Dropped images and audio attachments
├── inbox/                     # Hot folder for background OCR & audio drop
└── .git/                      # Optional Git repository for auto-sync
```

### 5.2 Settings Location
- **Windows**: `%AppData%\syki\config.json`, `agents.yaml`, `lessons/<agent>.md`
- **macOS**: `~/Library/Application Support/syki/config.json`, `agents.yaml`
- **Important**: Edit `config.json` only when the app is completely closed.

### 5.3 Supported AI Providers
- **Local**: Ollama (`http://127.0.0.1:11434`), LM Studio, LocalAI.
- **Cloud**: OpenAI (GPT-4o, o3-mini), Anthropic (Claude 3.7 / 3.5), Google Gemini (Gemini 2.5/2.0), DeepSeek (with automated `<think>` tag stripping), OpenRouter.
